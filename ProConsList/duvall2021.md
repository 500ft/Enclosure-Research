# Duvall et al. (2021): EPA Performance Testing Protocols for PM2.5 Air Sensors

**Source:** https://cfpub.epa.gov/si/si_public_record_report.cfm?dirEntryId=350785 (EPA/600/R-20/280)
**Evidence boundary:** Agency protocol/guidance report, not an experimental paper. Defines recommended test procedures, metrics, and target values for non-regulatory PM2.5 sensors; it does not certify any sensor and does not address meteorological (T/RH) channels.

## Sensors

No specific sensor models; applies to any PM2.5 air sensor used for ambient, outdoor, fixed-site, non-regulatory monitoring.

### Pros

- Defines base testing: at least three identical sensor units collocated with FRM/FEM reference monitors for a minimum of 30 days per site — a defensible precedent for this study's 30-day co-location target.
- Standardizes evaluation metrics: coefficient of determination, slope, intercept, RMSE/NRMSE, and data completeness, so results can be compared across studies.
- Distinguishes base (field) from enhanced (laboratory) testing, giving a tiered structure this study can mirror.

### Cons

- Non-regulatory guidance only; meeting the targets does not make data regulatory-grade.
- PM2.5-specific; targets do not transfer directly to temperature, RH, pressure, or gas channels.

## Physical Box, Materials, and Geometry

Not addressed; the protocol treats the sensor system as a unit and does not evaluate enclosure design.

### Pros

- Metric definitions are enclosure-agnostic, so enclosure variants can be compared under the same protocol.

### Cons

- Provides no guidance on enclosure, shielding, or siting microclimate; those must come from WMO-No. 8 and the shield literature.

## Selection Lessons for This Project

- Supports adopting 30-day collocation and the EPA metric set (R², slope, intercept, RMSE/NRMSE, completeness) for any PM/gas channel.
- Cannot justify enclosure design choices or meteorological-channel acceptance thresholds.
