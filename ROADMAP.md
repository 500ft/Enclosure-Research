# Roadmap — Enclosure Research (Outdoor Multi-Sensor Box)

_Last updated: 2026-06-23 · Horizon: 8 weeks (through ~2026-08-23)_

## Role in the portfolio

**Graduate-school equity.** This is real research under a real PI (NYU CUSP
IgNYte Lab, Prof. Augustin Guibaud). The single most valuable outcome here is not
the repo — it is a **co-authored paper and a strong recommendation letter.**
Optimize for that.

## Gating step (do this in week 1, before any further work)

This work is lab research, not a personal project, so the first action is a
conversation with the PI to settle:

- [ ] **Repository visibility and IP** — this repo is currently public; confirm
      whether NYU/lab policy and any publication embargo permit that, and switch
      to private if there is any doubt.
- [ ] **Authorship and licensing** — confirm intended authorship order and what
      license (if any) the PI wants before adding any license file.
- [ ] **Data timeline** — confirm whether the lab measurement data (sensor
      models, power, deployment logs, reference co-location) will land inside
      this 8-week window.

Everything below depends on the answers. Do not invest heavily until this is
settled.

## Where it is now

Strong literature foundation: 19-source matrix, per-paper sensor/box pros-cons
analyses, a PI-ready literature synthesis (PDF/DOCX), metrics scripts, and
deployment/calibration logging templates. Manuscript v1 exists but the results
section is a placeholder pending lab data.

## Two paths, by data availability

### If lab data arrives this window

- [ ] Ingest measurements with the existing metrics scripts (accuracy vs
      reference, calibration improvement, uptime/completeness, maintenance
      burden).
- [ ] Turn the manuscript results section from placeholder into real results.
- [ ] Target a submittable draft co-authored with the PI.

### If lab data does NOT arrive

- [ ] Reframe honestly as a literature-review + experimental-design contribution
      (a defensible standalone artifact).
- [ ] Do **not** oversell beyond what the data supports.

## Scope discipline

The `military-environmental-sensing` / `DifferentApplication` branch is a
separate framing bolted onto the core study. Decide with the PI whether it
belongs at all; if kept, keep it clearly separated so the core study reads as
focused, not scattered. Default: park or privatize it until the core paper has
real results.
